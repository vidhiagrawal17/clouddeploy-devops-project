# CloudDeploy — Multi-Environment DevOps Project

## About
This project demonstrates how to build and deploy a simple web application using DevOps tools.

## Environments
- Development (DEV)
- Staging
- Production (PROD)

## Technologies
- Git and GitHub
- Python and Flask
- Docker
- Kubernetes
- GitHub Actions
- AWS
- Terraform
- Prometheus and Grafana

## Learning Goals
- Understand version control.
- Build and containerize an application.
- Automate testing and deployment.
- Manage multiple environments.
- Learn cloud infrastructure and monitoring.
